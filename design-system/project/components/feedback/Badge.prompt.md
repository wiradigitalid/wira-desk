# Badge

Small status or eyebrow label — "GRATIS", "RINGAN", version tags, functional statuses.

```jsx
<Badge tone="brand" caps>Gratis</Badge>
<Badge tone="gold" appearance="soft" dot>Beta</Badge>
<Badge tone="success" dot>Aktif</Badge>
```

- **tone**: `brand` `neutral` `gold` `danger` `warning` `success`.
- **appearance**: `solid` · `soft` (default) · `outline`.
- **caps**: uppercase mono eyebrow treatment.
