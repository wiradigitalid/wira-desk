UX Architecture & Comparative Audit

Analisis perbandingan antarmuka bawaan lama (egui plain tabs) dengan Redesain Fluent 2 Terpadu.

✕

Old Interface (Baseline egui / Win32)

  • Horizontal Top Tabs: Membatasi skalabilitas penambahan kategori pengaturan dan navigasi keyboard yang kaku.
  • Plain Button Capturer: Input shortcut hanya berupa tombol bertuliskan teks tanpa visualisasi status kombinasi keyboard fisik.
  • Zero Spatial Feedback: Pengaturan Snapping dan Overlapping Stack hanya berupa angka slider murni tanpa preview visual posisi layar.
  • Isolated Dialogs: Kurangnya feedback visual status daemon (apakah hook aktif, elevated, atau sedang mengalami throttling).
✓

Fluent 2 Redesign Solution

  • Vertical Mica Sidebar: Sesuai panduan Windows 11 Human Interface Guidelines dengan aksesibilitas Tab-stop linear.
  • Visual Keycap Badges: Mode Listening dengan animasi visual denyut, live key detection, dan deteksi konflik modifier.
  • Live Layout Previews: Slider ratio stack terhubung dengan kalkulasi representasi DPI-aware horizontal offset.
  • 3-Tier Alert System Integration: Indikator status real-time di footer jendela dan system tray icon overlay.

3-Tier Error Protocol UX Visualization

Tier 1: Startup Fatal
Kegagalan Hook saat boot (misal diblokir Antivirus). Menampilkan tepat 1x MessageBox modal sebelum keluar.
Tier 2: Runtime Warning
Kegagalan non-fatal. Nol popup. Silent log + overlay titik merah kecil pada Tray Icon.
Tier 3: Runtime Critical
Hook mati saat runtime. Overlay silang merah pada Tray + tepat 1x Toast Notification OS.

Bagaimana Cara Kerja "Overlapping Stack Layout"?

Fitur ini terinspirasi dari kebutuhan produktivitas di layar laptop/monitor kecil di mana membuka 3 jendela berdampingan (tiling biasa) akan membuat tiap jendela terlalu sempit (< 33% lebar layar).

1. Lebar Nyaman (50% Layar)
Setiap jendela diatur memiliki lebar tetap 50% (dapat diubah via slider 30%-80%), sehingga area konten tetap lega untuk dibaca/diedit.
2. Offset Horizontal Merata
Hingga maksimal 3 jendela ditata bertingkat dari Kiri, Tengah, ke Kanan secara otomatis (cascade teratur), bukan bertumpuk menutupi 100%.
3. Tepian Selalu Klik-able
Sisa area travel memastikan tepi setiap jendela di belakangnya selalu tampak dan bisa langsung diklik dengan mouse kapan saja.

Design Iteration History

Dokumentasi setiap putaran iterasi desain UI/UX Wira Desk untuk review tim dan stakeholder.

Latest Iteration (v1.3)
v1.3 — Triple-Modifier Lock: Ctrl + Alt + Win Alignment
2026-08-24

Optimal Shortcut Ergonomics: Mengadopsi kombinasi 3-modifier Ctrl + Alt + Win (berjajar di pojok kiri bawah keyboard) untuk perlindungan tabrakan 100% dari Windows OS & aplikasi lain.

  • New Standard Default Snapping: Ctrl + Alt + Win + ← (Snap Kiri) dan Ctrl + Alt + Win + → (Snap Kanan).
  • New Standard Maximize & Stacking: Ctrl + Alt + Win + Enter (Layar Penuh) dan Ctrl + Alt + Win + ↓ (Overlapping Stack).
  • Improve Ergonomics: Sangat nyaman ditekan bersamaan dengan jari kelingking, manis, dan jempol kiri sekaligus tanpa perlu merenggangkan tangan.
