Windows 11 Fluent 2 — Toggle Switch 3-State Design System

Standar warna track dan thumb untuk membedakan Active ON vs Locked/Disabled ON

1. Matrix Perbandingan Visual 3-State

1. Active User Switch (ON)
Track: Bright Blue (#4CC2FF)
Thumb: Solid White (#FFFFFF)
Status: Dapat diklik/diubah
2. Locked / Read-Only (ON)
Track: Muted Gray (#323742)
Thumb: Slate Gray (#7B8496)
Status: Terkunci aktif oleh sistem
3. Inactive Switch (OFF)
Track: Dark (#282A30)
Thumb: Gray (#A0A6B4)
Posisi: Kiri (OFF)

2. Penerapan Nyata di General Settings

Auto-start on Boot
When enabled, Wira Desk starts automatically at sign-in.
Spatial Preservation (Per-Monitor Lock)
Locks window cycling strictly to the currently active physical monitor.
🔒 Core architectural guarantee (Always enforced)
Virtual Desktop Isolation
Prevents jumping across active Windows Virtual Desktop boundaries.
🔒 Core architectural guarantee (Always enforced)
UX Honesty Mode
Brings hanging or not-responding windows forward transparently.
🔒 Core architectural guarantee (Always enforced)
