📐 Solusi Layout: Slot Pembagian 2-Kolom (Auto-Wrap Text)

Arsitektur Text Slot Adaptif + Control Slot Berukuran Khusus per Komponen

1. Arsitektur Pembagian Kolom (Slot Budget Allocation)

Ya, ini sangat memungkinkan dan merupakan praktik terbaik (best-practice) dalam sistem Fluent 2. Masing-masing baris menghitung lebar slot teks secara matematis: text_width = total_width - control_width - gap.

Kolom Kiri (Text Slot)
Width: (Available Width - Control Width - Gap)
Fitur: Auto-wrap ke baris kedua bila deskripsi panjang!
Kolom Kanan (Control Slot)
Width: Disesuaikan per tipe kontrol:
• Toggle: 44 px
• Keycap: 140 px
• Slider: 180 px
