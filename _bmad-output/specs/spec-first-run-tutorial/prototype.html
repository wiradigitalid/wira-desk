Welcome to Wira Desk

Wira Desk switches between windows of the application you are already using, instead of every window on the system like Alt+Tab does. Cycling also stays on the current monitor and virtual desktop, rather than reaching across all of them.

Try switching windows

Open a second window of this application, then press the switch shortcut. Focus moves to the next window of the same application, on the same monitor.
